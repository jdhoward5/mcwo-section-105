# Source Sans 3

Variable upright and italic fonts, weights 200–900, from the Google Fonts distribution:

- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- Original filenames: `SourceSans3[wght].ttf` and `SourceSans3-Italic[wght].ttf`.
- Retrieved 2026-11-15; binaries are unmodified and renamed for local URLs.
- License: `SourceSans3-OFL.txt` (SIL Open Font License 1.1).

The lab serves these files locally; it makes no runtime requests to a font CDN.
